# Contributing

Use JDK 17 and the pinned Android tools in docs/DOCUMENTATION.md. Keep the standard APK core-free. Test new consoles with permitted content, publish matching source/licenses and record runtime evidence before marking support verified.

Run build, lint, security unit tests, packaging checks and the relevant host/device flow before submitting a change. Keep real device results separate from generic emulator results. Use small, meaningful commits; avoid generated binaries, private keys, machine paths, private saves and ROM collections.

Preserve the restrained grayscale design, small corner radii, explicit focus states and remote navigation. Every visible action must work or explain a concrete unavailable requirement. Do not add fake resume controls, download success or compatibility badges.

FireSpot project changes are GPL-3.0-or-later. Preserve upstream license/copyright notices and original CC0 game attribution. See NOTICE and the separate core release for component terms.
